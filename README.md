# 30-0 · LCK 올타임 로스터

룰렛으로 연도와 팀을 뽑고, 그 로스터에서 선수 한 명씩 데려와 다섯 자리를 채운다.
완성된 라인업으로 LCK 정규 시즌 30경기 전승에 도전하는 브라우저 게임.

플레이: https://kleo19.github.io/lck-roster/

## 데이터

- Oracle's Elixir 매치 데이터 (2016-2026 LCK 정규 시즌, LCK 컵 제외)
- 선수 219명 / 팀-연도 114개
- 지표: 경기당 킬, 분당 딜, 분당 CS, 15분 경험치차, 분당 시야점수

실제 LCK 팀 성적에 회귀해 얻은 가중치로 예상 승수를 계산한다.
분당 시야점수는 2018년부터만 기록이 존재해, 그 이전 선수는 나머지 네 지표로 평가한다.

Riot Games와 무관한 비공식 팬 제작물이며, Oracle's Elixir 역시 Riot의 공식 자료가 아니다.
